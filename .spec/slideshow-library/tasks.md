### Phase 2 — Slide-level attributes
- [ ] T003 **`slide_bg()` global** — wraps all background data attributes from https://revealjs.com/backgrounds/. Supports: `color`, `gradient`, `image`, `size`, `position`, `repeat`, `opacity`, `video`, `video_loop`, `video_muted`, `iframe`, `interactive`, `transition`. Red: undefined. Green: `slide_bg(color="#09b")` → `data-background-color="#09b"`, `slide_bg(image="pic.jpg", opacity=0.5)` → `data-background-image="pic.jpg" data-background-opacity="0.5"`, empty call → `""`. Validate that `opacity` is 0-1, `repeat` is a valid CSS value.
- [ ] T004 **`slide_transition()` global** — wraps `data-transition`, `data-transition-speed`, `data-background-transition` from https://revealjs.com/transitions/. Supports: `effect` (none/fade/slide/convex/concave/zoom), `speed` (default/fast/slow), `background`, `in`/`out` variants (e.g. `"slide-in"`). Red: undefined. Green: `slide_transition("zoom")`, `slide_transition("slide", speed="fast")`, invalid effect raises `ValueError`.
- [ ] T005 **`auto_animate_pair()` global** — produces two `<section data-auto-animate>` elements from https://revealjs.com/auto-animate/. Takes `(slide_a, slide_b, easing=None, duration=None, unmatched=None, id=None, restart=False)`. Red: undefined. Green: basic pair, pair with easing/duration, pair with `data-id` matching elements inside each slide, pair with `restart=True`. The output must be valid sibling `<section>` tags.
- [ ] T006 **`auto_animate_attrs()` global** — per-element auto-animate settings: `data-id`, `data-auto-animate-easing`, `data-auto-animate-duration`, `data-auto-animate-delay`, `data-auto-animate-unmatched`. Returns attribute string for use on arbitrary elements inside auto-animated slides. Red: undefined. Green: `auto_animate_attrs(data_id="box")` → `data-id="box"`, combined settings.
- [ ] T007 **`slide_visibility()` global** — `data-visibility` from https://revealjs.com/slide-visibility/ Supports: `"hidden"`, `"uncounted"`. Red: undefined. Green: `slide_visibility("hidden")` → `data-visibility="hidden"`, `slide_visibility("uncounted")` → `data-visibility="uncounted"`, invalid value raises `ValueError`.
- [ ] T008 **`auto_slide()` global** — `data-autoslide` from https://revealjs.com/auto-slide/. Takes milliseconds (int > 0). Red: undefined. Green: `auto_slide(5000)` → `data-autoslide="5000"`, zero/negative raises `ValueError`.
- [ ] T009 **`slide_state()` global** — `data-state` from https://revealjs.com/markup/#slide-states. Red: undefined. Green: `slide_state("make-it-pop")` → `data-state="make-it-pop"`.
- [ ] T010 **`data_timing()` global** — `data-timing` from https://revealjs.com/speaker-view/. Takes seconds (int/float > 0). Red: undefined. Green: `data_timing(120)` → `data-timing="120"`.

### Phase 3 — Inline element helpers
- [ ] T011 **`fragment()` filter** — wraps content in a span with `class="fragment [style]"` from https://revealjs.com/fragments/. Supports all 20+ built-in styles as enum validation: fade-in (default), fade-out, fade-up, fade-down, fade-left, fade-right, fade-in-then-out, fade-in-then-semi-out, current-visible, grow, shrink, semi-fade-out, strike, highlight-red, highlight-green, highlight-blue, highlight-current-red, highlight-current-green, highlight-current-blue, custom. Also supports `custom_class="blur"` for custom fragments, `index=N` for `data-fragment-index`, nested fragments. Red: `"text" | fragment` is unchanged. Green: `"text" | fragment` → `<span class="fragment">text</span>`, `"warn" | fragment(style="highlight-red")` → `<span class="fragment highlight-red">warn</span>`.
- [ ] T012 **`notes()` filter** — wraps text in `<aside class="notes">...</aside>` from https://revealjs.com/speaker-view/. Red: unchanged. Green: `"check Q3" | notes` → `<aside class="notes">check Q3</aside>`.
- [ ] T013 **`code_block()` global** — generates complete `<pre><code>` block from https://revealjs.com/code/. Takes `(source, language=None, trim=True, noescape=False, line_numbers=None, ln_start_from=None)`. `line_numbers` can be a string like `"3,8-10"` or step-by-step `"1|2-3|4,6-10"`. Red: undefined. Green: basic code block, with line numbers, with step-by-step highlights, with language class, with `data-ln-start-from`.
- [ ] T014 **Media helpers** — `video_embed(src, autoplay=False, muted=False, loop=False, ignore=False, lazy=False, preload=False)` and `audio_embed(src, ...)` and `iframe_embed(src, autoplay=False, preload=False)` from https://revealjs.com/media/. Generates the appropriate HTML element with `data-autoplay`, `data-src` (when lazy=True), `data-preload`, `data-ignore`. Red: undefined. Green: basic element, autoplay element, lazy-loaded element.
- [ ] T015 **Lightbox helpers** — `preview_image(src, fit=None)` and `preview_video(src, fit=None)` and `preview_link(href, fit=None)` from https://revealjs.com/lightbox/. Generates element with `data-preview-image`, `data-preview-video`, `data-preview-link` and optional `data-preview-fit` (scale-down/contain/cover). Red: undefined. Green: `<img src="x.png" data-preview-image>`, `<a data-preview-link="https://...">link</a>`.
- [ ] T016 **Layout class helpers** — `fit_text()` → `class="r-fit-text"`, `stretch()` → `class="r-stretch"`, `frame()` → `class="r-frame"`, `stack(content)` → wraps content in `<div class="r-stack">...</div>` from https://revealjs.com/layout/. Red: undefined. Green: fit text, stretch, stack with multiple elements.
